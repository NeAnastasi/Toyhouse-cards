# Набор карточек для Toyhouse

Коллекция из 8 кастомных HTML-блоков для оформления профилей и страниц персонажей на платформе Toyhouse.
Половина карточек создавалась под конкретные запросы пользователей, остальные - для собственного использования и для выставления как free to use вариантов оформления.

---

## Технологии

- **HTML**
- **CSS**
- **Bootstrap**
- **Inline-стили**

---

## Что внутри

- Разные варианты карточек
- Адаптивная вёрстка
- Готовые к использованию блоки для Toyhouse

---

## Запуск

Проект состоит из статических HTML-страниц. Достаточно открыть любой файл в браузере.
